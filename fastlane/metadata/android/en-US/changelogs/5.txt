Long-press any node to move it: it no longer needs to be selected first. The link button takes the place of the edit button (double-tap a node to edit it). A link can be typed without https://. A node can now have no text, as in Freeplane. With a physical keyboard, Freeplane's keys work: Enter, Insert or Tab, Delete, Ctrl+arrows, Ctrl+Z, Ctrl+Y, Ctrl+S, F2, Home, End, Page Up and Page Down.

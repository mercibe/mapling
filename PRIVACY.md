# Privacy policy

*Version française plus bas.*

Mapling collects no data. It has no account, no ads, no analytics, and no network access: the Android app does not even ask for the permission to use the internet.

- **Your maps**: Mapling reads and writes only the documents you choose, through Android's document picker (Google Drive, the phone's storage, or another provider). They go nowhere else.
- **Kept on your device only**, in the app's private storage, and deleted when you uninstall it: the list of your ten most recent maps (name and access to the document), and drafts of unsaved changes, deleted once the map is saved or the changes discarded. This data is excluded from Android's backups.
- **Links**: "Source code" in About opens the project's page in your browser; Mapling itself sends nothing.

## Web version

The web version (<https://benoitmercier.me/mapling-web/>) runs entirely in your browser. Your browser downloads the page and its files from the web host like any web page; after that, Mapling sends nothing.

- **Your maps**: the browser reads the file you open on your computer; it is never uploaded. Saving downloads a copy.
- **Kept in your browser only**, in the local storage of the site `benoitmercier.me`: drafts of unsaved changes, deleted once you confirm the copy is saved or discard the changes, and the names of the maps whose hidden-content notice was already shown. Clearing the site's data in your browser deletes them.
- **Web host**: like any web site, the host keeps standard access logs (IP address, date, requested file). Mapling adds no cookie, analytics or third-party script.

Questions: open an issue on <https://github.com/mercibe/mapling>.

# Politique de confidentialité

Mapling ne collecte aucune donnée. Aucun compte, aucune publicité, aucune mesure d'audience, aucun accès au réseau : l'application Android ne demande même pas la permission d'utiliser Internet.

- **Vos cartes** : Mapling ne lit et n'écrit que les documents que vous choisissez, par le sélecteur de documents d'Android (Google Drive, le stockage du téléphone ou un autre fournisseur). Elles ne vont nulle part ailleurs.
- **Gardé sur votre appareil seulement**, dans le stockage privé de l'application, et effacé quand vous la désinstallez : la liste de vos dix cartes les plus récentes (nom et accès au document), et les brouillons des modifications non enregistrées, effacés dès que la carte est enregistrée ou les modifications abandonnées. Ces données sont exclues des sauvegardes d'Android.
- **Liens** : « Code source », dans À propos, ouvre la page du projet dans votre navigateur ; Mapling lui-même n'envoie rien.

## Version Web

La version Web (<https://benoitmercier.me/mapling-web/>) fonctionne entièrement dans votre navigateur. Celui-ci télécharge la page et ses fichiers depuis l'hébergeur, comme toute page Web ; ensuite, Mapling n'envoie rien.

- **Vos cartes** : le navigateur lit le fichier que vous ouvrez sur votre ordinateur ; il n'est jamais envoyé. Enregistrer télécharge une copie.
- **Gardé dans votre navigateur seulement**, dans le stockage local du site `benoitmercier.me` : les brouillons des modifications non enregistrées, effacés dès que vous confirmez que la copie est enregistrée ou que vous abandonnez les modifications, et les noms des cartes pour lesquelles l'information sur le contenu invisible a déjà été affichée. Effacer les données du site dans votre navigateur les supprime.
- **Hébergeur** : comme pour tout site Web, l'hébergeur tient des journaux d'accès ordinaires (adresse IP, date, fichier demandé). Mapling n'ajoute ni témoin (cookie), ni mesure d'audience, ni script tiers.

Questions : ouvrez un ticket sur <https://github.com/mercibe/mapling>.
